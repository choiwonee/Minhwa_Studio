# 테스트 파라미터
터미널 실행 후 루트 폴더 안에서 실행

python 파일명.py `
 --input 'images/파일명.jpg' `
 --output-dir 'outputs' `
 --model-id '모델명' `
 --device 'cpu'

# ---------------------------------------- 모델 ------------------------------------------------------
"depth-anything/Depth-Anything-V2-Large-hf": "DAv2L"

모델명 생략 시 depth-anything V2 Large hf 기본값
디바이스 생략 시 사용자 환경에 따라 GPU/CPU 선택

※ 주의 : 여러 라인으로 파라미터를 입력하기 위해 백틱(`)을 사용함. 마지막 라인에는 사용하지 않음.
#----------------------------------------- 파라미터 ------------------------------------------------------

후처리 파리미터는 기본 값이 설정되어 있음.
파라미터 값을 설정하지 않아도 기본값으로 계산됨.

#----------------------------------------- 예시 ------------------------------------------------------

python main.py `
 --input 'images/화첩.jpg' `
 --output-dir 'outputs' `
 --device 'cpu' `
 --normal-scale 50.0
