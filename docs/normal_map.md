# 파이프라인 흐름

이미 학습된 Depth Anything V2 모델을 사용하여 깊이 맵을 추론(Inference)하는 단계까지만 딥러닝을 사용한다.  
그 이후의 모든 과정은 전통적인 컴퓨터 그래픽스 공식과 후처리 필터를 사용하며,  
파라미터 튜닝을 통해 최종 결과물의 품질을 높이는 것을 목표로 한다.  

[1] 입력 이미지 로드  
[2] 깊이맵 생성 (Depth Estimation)   
[3] 노멀맵 생성 (depth_to_normal)  
[4] 빛 방향 추정 (estimate_light_vector)  
[5] 셰이딩 계산 (phong_shading)  
[6] 감마 보정 (shading_gamma)  
[7] 그림자 확산 (depth_shadow_diffusion)  
[8] 이미지 블렌딩 (blend_image)  
[9] 깊이 기반 보정 (contrast, shadow, highlight)  
[10] 최종 합성 이미지 저장

# 노멀맵 계산

## 💡 **depth_to_normal (노멀맵) 함수 정리**
2D 깊이맵은 각 픽셀의 '높낮이(거리)' 정보만 가진다.
이를 3D 조명 계산에 사용하려면 각 픽셀 표면이 '어느 방향을 바라보는지'에 대한 3D 벡터 정보가 필요하다.
노멀맵은 이 방향 정보를 RGB 색상(X, Y, Z축)으로 저장한다.
Gradient는 이미지의 전반적인 큰 경사(흐름)를 계산하는 데 사용된다.
Sobel은 노이즈에 강하고 물체의 윤곽선(엣지)을 더 선명하게 강조하는 데 특화되어 있다.
alpha와 beta 가중치로 두 결과를 혼합하여, 부드러우면서도 선명한 노멀맵을 생성한다.  

---

## ⭐ **Gradient (기울기)**
`np.gradient`는 이미지 값이 어느 방향으로 얼마나 변하는지를 계산한다.  
즉, 픽셀값이 변하는 방향과 크기를 알려준다.  
값이 일정하면 → Gradient = 0 (평평)  
값이 급격히 변하면 → Gradient ↑ (경사가 심함)  
Gradient는 단순히 픽셀 값의 변화율이다.  

---

## ⭐ **Sobel 연산자**
Sobel = Gradient + 강조 효과  
`cv2.Sobel`은 이미지의 에지(윤곽)를 강조하면서 기울기를 잡아내는 필터다.  
실제 이미지에는 노이즈도 있고, 미세한 변화도 존재한다.  
Sobel은 단순 Gradient 대신 주변 픽셀 여러 개를 가중 평균으로 계산한다.  
이렇게 하면 작은 흔들림(노이즈)은 무시되고 큰 변화(윤곽선)는 더 두드러지게 나타난다.  

Gradient와 Sobel 모두 깊이맵에서 높낮이가 확 달라지는 구간,  
즉 “경사가 있는 부분”을 찾기 위해 사용된다. (보통 물체의 윤곽)  
두 방식은 성격이 조금 달라 서로 보완된다.  

- Gradient → 단순하고 직관적인 경사 계산기  
  → 큰 흐름(전반적인 경사 방향)을 잘 잡는다.  
- Sobel → 경계를 더 선명하게 드러내는 필터  
  → 작은 윤곽, 디테일을 잘 살린다.  

따라서 코드에서 `alpha * gradient + beta * sobel` 형태로 두 장점을 섞어 사용한다.  

---

## ⭐ **정규화 (Normalization)**
기울기를 얻었을 때 벡터 길이가 제각각이므로,  
(nx, ny, nz) 벡터를 길이가 1인 벡터로 맞춰야 “진짜 노멀 벡터”가 된다.  
즉, 방향만 남기고 크기는 버린다.  

노멀(normal) 벡터는 “표면이 어느 방향을 바라보는가”를 나타내는 벡터이다.  
방향만 중요하고, 크기는 중요하지 않으며 보통 (-1 ~ 1) 범위를 가진다.  

Gradient나 Sobel로 기울기를 구하면 (nx, ny, nz) 값들이 커질 수 있다.  
벡터 길이가 제각각이면 표면 방향 정보가 왜곡된다.  
따라서 벡터의 길이를 1로 정규화하여 방향만 남기고 크기를 제거해야 한다.  
그래야 셰이딩 계산(빛과의 각도)이 올바르게 수행된다.  

하지만 GPU나 이미지 저장 포맷은 음수 색을 지원하지 않기 때문에,  
(-1 ~ 1) 범위를 (0 ~ 1)로 매핑하여 RGB 값처럼 표현한다.  
이렇게 해야 RGB 이미지처럼 다룰 수 있다.  

정규화를 하지 않으면 “노멀맵”이 아니라 단순한 “벡터 크기 지도”가 되며,  
정규화를 해줘야 빛 계산 시 올바른 표면 방향이 나온다.
